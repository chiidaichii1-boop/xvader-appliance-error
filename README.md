## Entry

A washing machine reports the most honest fault it knows, in its own
flat, put-upon voice:

> Error E04: I ate a sock. The drum is jammed with its accomplice. Do not open the door; it knows what it did.

## How it works

`main.py` (Python 3.13, stdlib only) writes that single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).
It reads no input, uses no network, and is fully deterministic — the
same line, byte for byte, on every run.
